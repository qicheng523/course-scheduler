# 测试数据说明

给网站导入功能用的测试数据，由测试数据负责人维护。

## 文件列表

| 文件 | 内容 |
| --- | --- |
| [test_schedule.csv](test_schedule.csv) | 一名学生的课表（本学期 16 周） |

## 课表 CSV 格式（test_schedule.csv）

- **编码**：UTF-8（带 BOM），Excel / WPS 双击即可打开，中文不乱码
- **分隔符**：英文逗号
- **列定义**：

| 列名 | 说明 | 示例 |
| --- | --- | --- |
| 课程名称 | 文本 | 高等数学 |
| 星期 | 周一 ~ 周日 | 周一 |
| 开始时间 | 24 小时制 HH:MM | 08:00 |
| 结束时间 | 24 小时制 HH:MM | 09:40 |
| 周次 | 逗号分隔的周数或区间 | 1-16、4-16、1-8、5,7,9,11,13,15、12 |
| 地点 | 文本 | 教一101 |
| 教师 | 文本 | 王建国 |

> 注意：周次含逗号时必须用英文双引号包起来（参考"线性代数习题课"那一行）。

## 数据设计要点

这份数据刻意覆盖了各种情况，方便测试"空闲时间计算"：

- 常规每周课（如 1-16 周）
- 期中才开始/提前结束的课（4-16、1-8、9-16）
- 单双周课（线性代数习题课，单周 5,7,9,11,13,15）
- 一次性讲座（第 12 周周一晚）
- 周末活动（周六社团）
- 空闲时间丰富的时段：多数晚上、周三上午、周五下午之后
