# 课表排程器 · 功能说明

> **仓库地址**：https://github.com/qicheng523/course-scheduler
> **一句话**：把真实课表输进去，系统算出每天的空闲时间，把作业自动排进空档，出一份周报告，能打卡，能导出周报。

---

## 1 它解决什么问题

大学生知道"这周有作业"，但算不清"哪个晚上有空、该先写哪个"。课表每周重复，睡觉和吃饭占掉固定时段，剩下的空档碎且不规律，靠脑子排必乱。

这个工具把这件事自动化：**课表 + 固定作息 → 空闲时段 → 任务自动落位 → 周报告**。全部数据在一个本地 SQLite 文件里，不联网、不登录。

---

## 2 功能清单

### 2.1 课程管理

- 内置 **19 个真实课次**（8 门课，周一到周五），来自真实课表，教师名已脱敏。
- 支持**新增 / 修改 / 删除**课程，时间为 `HH:mm`，数据库内存分钟整数。
- **时间冲突自动拦截**：同一星期、时间段重叠时返回 409 和中文提示，例如「这门课和「高等数学AI」时间冲突」。
- 非法输入（星期不在 1–5、时间格式错、结束早于开始）返回 422 中文说明。

### 2.2 空闲时间计算

- 每天窗口固定 **07:30–21:30**，按 **15 分钟**对齐。
- 扣掉当天的课，再扣掉固定事件（睡觉、早饭、午饭、午休、晚饭、周六英语班）。
- **晚自习 19:00–21:00 是"特殊时段"**，不是普通空闲：
  - 前后各留 10 分钟走路（18:50–19:00、21:00–21:10 不排任务）；
  - 任务块**不许横跨** 19:00 或 21:00；
  - 空闲段在 **18:50 / 19:00 / 21:00 / 21:10** 四个时刻切开；
  - 周六周日没有晚自习，也不切。
- 切完不足 15 分钟的碎片自动丢弃。

以 2026-11-19（周四）为例，扣掉 4 节课和固定事件后，空闲段是 5 段：

| 时间段 | 时长 | 类型 |
|---|---|---|
| 09:40–10:10 | 30 分钟 | 普通空闲 |
| 15:40–16:10 | 30 分钟 | 普通空闲 |
| 18:30–18:50 | 20 分钟 | 普通空闲 |
| 19:00–21:00 | 120 分钟 | 晚自习 |
| 21:10–21:30 | 20 分钟 | 普通空闲 |

### 2.3 自动排程

- 候选时间排序：**晚自习 > 周末整天 > 工作日白天空档**，同档取最早，起点对齐 15 分钟网格。
- 任务排序：**优先级高的先排**，同优先级按截止时间早的。
- 放得下就整段放；放不下才切块，每块 **45–120 分钟**，最后一块不少于 15 分钟。
- **零重叠**：任务块不与课程、固定事件、其他任务块重叠。
- **结果可复现**：同样的输入跑两次，结果完全一样（排序确定，不用随机）。
- **排不下不丢**：进入"未排"列表，并写一句人能看懂的原因，例如「这一周的空档最长只有 30 分钟，任务需要 45 分钟」。
- 同一周重复生成会**覆盖**旧计划，不会叠加。

实测：5 条任务、本周 375 分钟，生成结果是 **45 个块、5 个任务全部排进**（周一至周五的晚自习各一段）。

### 2.4 计划管理

- **加任务**：标题、类别（作业 / C语言 / 项目 / 刷题 / CS50）、预计时长、截止时间、优先级。
- **删除一周计划**：连同这一周的时间块和打卡记录一起删掉，任务回到"未排"。
- **删除单个任务块**：把某个任务从计划里拿掉，再生成时会重新安排。
- **修改任务块时间**：只改时间不改日期，带五条校验——15–120 分钟、落在 07:30–21:30、不跨 19:00/21:00、不与同一天其他块重叠、课和固定事件不能改。

### 2.5 打卡与统计

- 打卡是**幂等**的：同一天同一任务重复打卡不报错、不重复计数，接口用 `created` 区分首次和重复。
- 打卡状态以服务端为准（`blocks[].done`），换浏览器、开无痕窗口都不会丢。
- 周统计给四个指标：**已排任务数、已完成、未排、已排总时长**，并按 7 天和类别分别汇总。

### 2.6 导出周报

- `GET /api/export.md` 生成 UTF-8 的 Markdown 周报：概览、每天安排、未排任务及原因、打卡记录。
- 已打卡的任务后面带 ✅，浏览器点一下直接下载。

### 2.7 工程质量

- **57 个自动化测试**（`pytest`），覆盖课程接口、空闲段算法、排程、计划管理、打卡、统计、导出。
- **GitHub Actions CI**：每次 push 自动装依赖 → 环境自检 → 跑测试 → 重置并重灌种子数据核对条数。
- 测试全部使用内存数据库，不碰真实数据文件。

## 3 怎么运行

需要 Python 3.12。Windows 下在项目根目录依次执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\reset_db.py --yes
.\.venv\Scripts\python.exe scripts\seed.py
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

浏览器打开 `http://127.0.0.1:8000/`，点「生成本周计划」即可看到排程结果。
数据库是一个文件 `data/app.db`，删了重跑上面第 3、4 条命令即可恢复演示数据。

跑测试：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

## 6 接口清单

| 方法 | 路径 | 作用 |

## 8 已知限制

- **单人本地工具**：没有账号系统，数据只有一份，换电脑要拷 `data/app.db`。
- **课程只支持周一到周五**：真实课表没有周末课，所以周末不排课。
- **晚自习固定 19:00–21:00**，不可配置。
- **时间块只支持改时间**，不支持拖拽换天；要换天就删掉重新生成。
- **没有导入课表功能**：换课表要改 `data/seed-courses.txt` 再重跑 seed。
- **任务类别固定 5 类**（作业 / C语言 / 项目 / 刷题 / CS50）。
