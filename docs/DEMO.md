## 1 演示录屏 v1（11-22 任务卡 §3 任务 2）

- **要求**：2–3 分钟，按答辩 5 步走一遍；口播或字幕都行，重点是流程完整、不卡顿
- **演示状态已就绪**（B 已跑好）：`reset_db --yes` → `seed.py` → 生成了 2026-11-16 周的计划（45 块、任务 5/5 全排）
- **录屏前**（PowerShell，项目根目录）：

  ```powershell
  .\.venv\Scripts\Activate.ps1
  python -m uvicorn app.main:app --reload
  ```

  浏览器打开 <http://127.0.0.1:8000>，按 F11 全屏再开始录。

### 五步怎么走（每步 30–40 秒）

| 步 | 点哪里 | 说什么 |
|---|---|---|
| 1 首页 | 打开 `/` | "这是本周报告——输入课表后，系统自动算出空闲时间、把任务排进空档" |
| 2 本周报告 | 看周视图 | "课程、固定事件、任务三种块零重叠；晚自习自动被利用" |
| 3 今天做什么 | 看当天列表 | "每个任务块 15–120 分钟，不横跨 19:00 / 21:00 的边界" |
| 4 打卡 | 点任务的「打卡」 | "打卡后变灰加 ✅；再点一次也不会重复计数——这叫幂等" |
| 5 统计/导出 | 看统计卡 + 点「导出周报」 | "四个数字一目了然；导出 .md 文件，中文不乱码，7 天都在" |

### 录完做什么

1. 视频存本机或网盘 → 链接贴到 §3
2. `evidence/D06/` 里放一张**封面截图**（命名 `B-demo-cover.png`）+ 一行说明（时长、录制日期）

> ⚠️ 第 4、5 步依赖 A 的界面（打卡按钮/统计卡/导出链接，11-22 16:00 检查点）。
