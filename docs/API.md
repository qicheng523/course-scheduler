## 0 时间模型（全项目唯一真源）

### 9 节课，逐节写死（**禁止用公式推**）

| 节次 | 开始 | 结束 | 分钟 |
|---|---|---|---|
| 1 | 08:00 | 08:45 | 45 |
| 2 | 08:55 | 09:40 | 45 |
| 3 | 10:10 | 10:55 | 45 |
| 4 | 11:05 | 11:50 | 45 |
| 5 | 14:00 | 14:45 | 45 |
| 6 | 14:55 | 15:40 | 45 |
| 7 | 16:10 | 16:55 | 45 |
| 8 | 17:05 | 17:50 | 45 |
| 9 | 18:00 | 20:35 | **155（晚自习）** |

- 节次间隔是 `10 / 30 / 10 / 130 / 10 / 30 / 10 / 10 / 155` 分钟，**不均匀**。
  用 `08:00 + (n-1)×45` 推，第 5 节会算成 11:00（实际 14:00），整个排程全错。
- 数据库：时间一律存 **距 0 点的分钟整数**（08:00 → `480`，20:35 → `1235`）。
- 接口：时间一律收发 **`"HH:mm"` 字符串**（`"08:00"`）。转换只在 `app/services/` 里做，别在路由里写。

### 三条硬规则

1. **星期只有 1–5**（1=周一 … 5=周五）。6/7 → 422。周末没有课，整天可用。
2. **晚自习 18:00–20:35 不是课程**，是**空闲块**，可以往里排任务——它是工作日最大的一块时间。
3. 可用窗口 **07:30–21:30**，粒度 **15 分钟**，任务结束不得晚于 21:30。

## 1 通用约定

- 地址：`http://127.0.0.1:8000`，全部 JSON、UTF-8。
- 列表统一返回 `{"items": [...], "total": n}`，不要直接返回数组。
- 字段名一律 **snake_case 英文**，值可以是中文。
- 错误返回：
  - 参数非法 → **422**（FastAPI 默认格式，前端直接显示即可）
  - 不存在 → **404**，`{"detail": "课程不存在"}`
  - 时间冲突 → **409**，`{"detail": "时间冲突：周一 08:00-09:40 已有「高等数学AI」"}`
- 前端（A）显示错误时，取 `detail`；是字符串就直接显示，是数组就显示"输入格式不对"。

## 3 课程 · D2 实现

### 3.1 `GET /api/courses?term=2026f`

```json
{
  "items": [
    {
      "id": 1,
      "name": "高等数学AI",
      "weekday": 1,
      "start": "08:00",
      "end": "09:40",
      "location": "1-0206",
      "teacher": "老师C",
      "term": "2026f"
    }
  ],
  "total": 1
}
```

### 3.2 `POST /api/courses` → **201**

请求：

```json
{
  "name": "高等数学AI",
  "weekday": 1,
  "start": "08:00",
  "end": "09:40",
  "location": "1-0206",
  "teacher": "老师C"
}
```

响应（201）：返回带 `id` 的整条记录，字段同 3.1 里的一项。

校验规则（**一条都不许省**）：

| 情况 | 结果 |
|---|---|
| `name` 为空或超过 40 字 | 422 |
| `weekday` 不在 1–5 | 422 |
| `start` / `end` 不是 `HH:mm` | 422 |
| `start >= end` | 422 |
| 同一 `weekday` 下，与已有课程时间**重叠** | 409 |
| `location` / `teacher` 不填 | 允许，存 `null` |

> 重叠判断：`start < 已有.end 且 end > 已有.start`（首尾相接不算重叠，例如 09:40 结束、09:40 开始可以）。

### 3.3 `PUT /api/courses/{id}` → **200**

请求体同 3.2（可只带要改的字段，未带的保持不变），返回更新后的整条记录。`id` 不存在 → 404；改完与别的课冲突 → 409（**不能和自己比**）。

### 3.4 `DELETE /api/courses/{id}` → **204**（无响应体）

`id` 不存在 → 404。

## 4 `GET /api/slots?date=2026-11-18` · D3 实现

把某一天切成"有课"和"空闲"两类，只返回 **≥ 15 分钟** 的空闲块，按时间排序：

```json
{
  "date": "2026-11-18",
  "weekday": 3,
  "blocks": [
    {"start": "07:30", "end": "08:00", "minutes": 30},
    {"start": "09:40", "end": "10:10", "minutes": 30},
    {"start": "11:50", "end": "14:00", "minutes": 130},
    {"start": "15:40", "end": "16:10", "minutes": 30},
    {"start": "17:50", "end": "18:00", "minutes": 10},
    {"start": "20:35", "end": "21:30", "minutes": 55}
  ]
}
```

> 上例是示意，`17:50–18:00` 只有 10 分钟，**实际会被丢掉**（粒度 15）。周六日整天是 `07:30–21:30` 一整块。
> **晚自习 18:00–20:35 会出现在空闲块里**，不进课程列表。

## 5 任务 · D5 实现

### 5.1 `GET /api/tasks?status=open`

```json
{
  "items": [
    {"id": 5, "title": "高数作业 3.2", "due": "2026-11-20T22:00", "minutes": 90, "priority": 2, "status": "open"}
  ],
  "total": 1
}
```

### 5.2 `POST /api/tasks` → **201**

```json
{"title": "高数作业 3.2", "due": "2026-11-20T22:00", "minutes": 90, "priority": 2}
```

- `minutes`：预计时长（分钟，15 的倍数），必填，> 0。
- `priority`：可选 1–3（1 最高），默认 2。
- `due`：ISO 时间字符串，可空（空 = 没有截止日期）。

## 6 `POST /api/plan/generate` · D6 实现

请求：

```json
{"week_start": "2026-11-17"}
```

响应：

```json
{
  "week_start": "2026-11-17",
  "blocks": [
    {"id": 101, "date": "2026-11-18", "start": "18:00", "end": "19:30", "minutes": 90,
     "task_id": 5, "task_title": "高数作业 3.2"}
  ],
  "unscheduled": [
    {"task_id": 7, "task_title": "英语听力练习", "reason": "截止前剩余可用 60 分钟，任务需要 120 分钟"}
  ]
}
```

- **同一个任务可以被拆成多个 `blocks`**（整段放不下才切，切块 45–120 分钟）。
- 块与块、块与课**不许重叠**。
- `unscheduled` 必须给**人话原因**（D7 要展示"为什么没排下"）。
- 重复调用同一周：先清掉该周未打卡的旧块再重排；已打卡的块保留。
