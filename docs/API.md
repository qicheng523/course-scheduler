# API · 三个人的合同（v0.1，2026-11-17 冻结）

> **这份文件是 A、B、C 三个人共同的约定。** 谁都不许自己偷偷改字段名。
> 改一行 → 群里说 → 改这里 → 记一行变更 → 通知另外两个人。
>
> 为什么要有它：A 做网页、B 灌数据、C 写后台，三个人看同一份字段清单才不会各写各的。

---

## 0 两条总规矩

1. **数据库里时间存"分钟数"**（8:00 = 480），**接口上时间用 `"HH:mm"` 字符串**（`"08:00"`）。转换只在 C 的后台做。
2. 所有接口返回 **JSON**；出错返回 `{"detail": "中文说明"}`，`detail` 要能直接给用户看。

## 1 六张表（C 负责建，B 灌数据按这个来）

### ① `course` 课程（每周重复，只有周一到周五）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | 整数，自增 | 主键 |
| name | 文本 | 课程名，如"高等数学AI" |
| weekday | 整数 1–5 | 1=周一 …… 5=周五 |
| start_min | 整数 0–1439 | 开始时间（分钟） |
| end_min | 整数 1–1440 | 结束时间（分钟），必须 > start_min |
| location | 文本，可空 | 教室，如"28-A303" |
| term | 文本 | 学期，固定 `2026f` |

### ② `fixed_event` 固定事件（睡觉、三餐、英语班）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | 整数，自增 | |
| name | 文本 | 如"睡觉""午饭""英语班" |
| weekday | 整数 1–7 | 周一到周日 |
| start_min / end_min | 整数 | 同上 |
| note | 文本，可空 | 备注 |

### ③ `task` 任务（作业、复习、刷题…）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | 整数，自增 | |
| title | 文本 | 如"线性代数第二章" |
| category | 文本 | `作业` / `C语言` / `项目` / `刷题` / `CS50` |
| duration_min | 整数 | 预计用时，> 0 |
| deadline | 文本 | ISO 时间，如 `2026-11-20T23:59:00` |
| priority | 整数 1–3 | 1 最高 |
| status | 文本 | `todo` / `scheduled` / `done` |

### ④ `plan` 周计划

| 字段 | 类型 | 说明 |
|---|---|---|
| id | 整数，自增 | |
| week_start | 文本 | 那周的周一，如 `2026-11-16` |
| created_at | 文本 | 生成时间 |

### ⑤ `block` 时间块（计划生成出来的"几点做什么"）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | 整数，自增 | |
| plan_id | 整数 | 属于哪份计划 |
| task_id | 整数，可空 | 空 = 这是课或固定事件，不是任务 |
| date | 文本 | `2026-11-18` |
| start_min / end_min | 整数 | 当天分钟数 |
| kind | 文本 | `course` / `fixed` / `task` / `free` |

### ⑥ `checkin` 打卡

| 字段 | 类型 | 说明 |
|---|---|---|
| id | 整数，自增 | |
| task_id | 整数 | 打的是哪个任务的卡 |
| date | 文本 | `2026-11-18` |
| done_at | 文本 | 打卡时间 |
| note | 文本，可空 | |

> **`(task_id, date)` 必须唯一**——同一天同一个任务只能打一次卡，重复打不报错也不重复计数（这叫"幂等"）。

## 3 接口长什么样（A 照这个做页面，B 照这个验数据）

### ① 查课程

```http
GET /api/courses?term=2026f
```

```json
{
  "items": [
    {"id": 1, "name": "中国近现代史纲要", "weekday": 1, "start": "08:00", "end": "09:40", "location": "28-A303"},
    {"id": 2, "name": "高等数学AI",       "weekday": 1, "start": "14:00", "end": "15:40", "location": "1-0206"}
  ],
  "total": 19
}
```

### ② 新增课程

```http
POST /api/courses
Content-Type: application/json

{"name": "高等数学AI", "weekday": 1, "start": "14:00", "end": "15:40", "location": "1-0206"}
```

成功：`201` + 返回这条记录（带 `id`）。

### ③ 修改 / ④ 删除

- `PUT /api/courses/{id}`：body 同新增，成功 `200`
- `DELETE /api/courses/{id}`：成功 `204`（没有内容）

### 错误码（A 要按这个显示中文）

| 情况 | 状态码 | 返回 |
|---|---|---|
| 星期不是 1–5 | 422 | `{"detail": "星期只能是 1 到 5（周六周日没有课）"}` |
| 时间格式不对 | 422 | `{"detail": "时间要写成 08:00 这样的格式"}` |
| 结束早于开始 | 422 | `{"detail": "结束时间必须晚于开始时间"}` |
| 和已有课程时间重叠 | 409 | `{"detail": "这门课和「高等数学AI」时间冲突"}` |
| 改/删的 id 不存在 | 404 | `{"detail": "课程不存在"}` |

> **409 是重点**：A 的页面要把这句话原样显示在表单下面，不要只显示"出错了"。
